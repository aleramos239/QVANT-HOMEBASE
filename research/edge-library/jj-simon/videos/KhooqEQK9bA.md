## Summary
Why people pass but don't get paid: they trade funded differently (more pressure), use the same goal on eval and funded, don't
understand variance, revenge trade / copy trade, and have no fixed risk system. His fix: eval = maximise P(+$3,000 before -$2,000)
"most likely a 1.5 risk-to-reward"; funded = maximise P(payout) x payout size, with a different static stop/target. Never set the
target from the chart (e.g. $800 one trade, $535 the next): use STATIC numbers per account state. Eval numbers stated:
**25 stop / 38 target, 50 / 76 when the opening candle is big, 12.5 / 19 when close to fair.** He tries to get through 10+ trades in
the AM session, trades past 11:00 only if accounts remain.

## Rules / numbers
- Eval goal: +$3,000 before -$2,000 -> 1.5R ("$2,000 to $3,000").
- Funded goal: expected value = P(payout) x payout size. Different R:R and different static $ stop / $ target per state (new, in
  profit, taking payouts, about to go live). "Sometimes super long, sometimes super short, sometimes 1.5 (rare)." Numbers not stated.
- **Static targets only**: find the static target with the best pass rate (eval) and the static one with the best EV (funded).
  Never fit the target to the chart; the firm "capitalises" on variable targets.
- **Never copy trade unless you make > $10,000 a month** (then you can replace lost accounts). Copying = same EV, more variance =
  "the number one reason funded accounts die". No revenge trading / adding on tilt.
- "Spread out your risk across all of your accounts."
- Same performance on eval and funded: prove it in a prop-firm backtest before touching a funded.
- Rules listed: $3,000 targets, winning days, consistency ("don't make more than half in one trade"), max loss, some daily loss limits,
  payout rules.

## Strategy as shown (NQ 1m, EVAL sizes)
| Rule | Detail |
|---|---|
| Fair price | the session open (09:30, 18:00, 20:00, 14:00); news: pre-news price |
| Continuation | opening candle direction, needs wick rejection the other way + break of structure; size by candle: opening candle 42 pts -> **50 stop / 76 target**; 14-pt candle -> 25 / 38 |
| Reversion | back toward the open on displacement or break of structure; "too close" skip |
| Static sizes | **25 / 38** standard; **50 / 76** big; **12.5 / 19** (half target, double contracts) when the open is closer; 9-14 pt trades only for an account that needs that little |
| 80 / 20 | at least 80 % of the target on the near side of the open; mid-candle entries allowed to keep that |
| Layering | add on each new displacement / break of structure while the reversion runs in your favour |
| Time | NY AM; "usually done after 11", but past 11:00 if accounts remain: only reversions WITH the trend (wait for the trend to turn) |
| Volume | aims for **more than 10 trades in the AM session** (one day: "only 10 trades in") |
| Evening | 18:00 continuation + one reversion; quiet -> 19-pt targets; if 38 taken, breakeven when it breaks structure against; exit/BE before 20:00 if the push didn't come |
| Asia 20:00 | continuation + reversions; A+ = Asia candle back toward 18:00 (continuation + reversion together) |
| Gap | 18:00: reversions toward filling the gap (higher-time-frame bias) |
| News | reversions to the pre-news price are his strongest trade |
| Tweet (unexpected news) | day is "kind of over"; only with the trend; 14:00 reversions to the post-tweet consolidation |
| Friday | a reversion late Friday (institutions exiting before the weekend) |
| London | not traded (asleep); same concept |
| Bad Asia | if Asia gives nothing, be more aggressive in NY AM |
- A losing continuation that displaces against you: you may exit (~1/3 to 1/4 of the stop) and send the other way; "can mess with things".
- New firms: buys ~20 accounts on a new firm to test it; recommends it to students if it pays.
- Weaker trades OK on evals ("worth a lot less than funded").
