No chart trades. A 7-step plan (Miro board) for starting prop firms with $1,000. Same trader as jj-simon-fair-price-rulebook.md. Claims $2M+ payouts now.

## The 7 steps (slide text + what he said)
1. Buy nothing yet. Prove the plan in replay first. One setup, one market, one session, fixed risk. "The test is 50 ACCOUNTS - not 50 trades."
2. Backtest 50 complete accounts. 50 distinct starts; eval -> funded -> payout / breach. Apply the firm's target, trailing drawdown (trail it at end of day), consistency and payout rules exactly. Count real withdrawals only (e.g. made $2,000 but can only withdraw $1,000; then is the next payout $800 or a breach?).
3. Did the 50 make money? Payouts after split minus ALL eval costs (+ resets, other costs). Exclude unpaid balances. Track: pass rate, failed, paid, active, net $, and average payout per funded (15 funded, $15k paid -> each new funded is worth ~$1,000). Win rate doesn't matter.
   - If not: change the risk-to-reward first (eval and funded separately: eval goal = pass, funded goal = payouts), then the strategy; re-test 50. "You're not going to pass more than 33% long run"; a 2R eval plan passing under 33% is not optimal.
4. All $1,000 goes to Lucid Flex 25K: most profitable in his sims; $50 each with the daily loss limit ON = 20 evals. "No need to risk the full account: cap each trade + day." Your best account may differ - test your own.
5. Trade exactly what you tested: same setup, same session, same risk plan; size trades below the DLL + remaining drawdown; use the funded plan you tested; broke a rule -> pause, log why, back to sim.
6. Get paid, measure, repeat: request a payout the moment you're eligible; protect the post-payout cushion; track actual cash minus all spend; compare with the 50-account test; build the bankroll from payouts before sizing up. Goal = payouts, not account balance.
7. Scale with the bankroll (cash set aside, not account size): $1,000 -> 25K evals; $3,000 -> 50K accounts (Lucid, Topstep, Tradeify, Funded Next - each paid him $150k+); $15,000 -> 150K accounts. Re-simulate each firm's rules before buying or sizing up.

## Numbers
- Risk of ruin = (1 - pass rate x payout rate) ^ number of evals you can buy. Example: 0.3 x 0.33 ~ 0.1 -> 0.9^20 ~ 12% (my sum). With his own Lucid Flex 25K stats 0.37 x 0.35 = 0.13 -> 0.87^20 ~ 6% (my sum).
- His Lucid Flex 25K: ~37% pass, ~35% payout rate, 4.2x ROI.
- Expected value = payout size x payout chance. Same edge: a smaller payout target = higher payout chance = lower risk of ruin (same EV). A 1R plan lowers ruin; a 4R plan may raise ROI.
- Plan shapes (target / max loss): Lucid Flex 25K $1,250 / $1,000 (1:1.25), 50K $3,000 / $2,000 (1:1.5), 150K $9,000 / $4,500 (1:2). So the best risk-to-reward differs per plan.
- Rough cost per funded: 25K ~$200 ($1,000 buys 5), 50K ~$300 ($3,000 buys 10), 150K ~$1,000 ($15,000 buys 15).
- Don't start with less than $1,000 ($200 = 4 evals: even a big edge can lose it all).
