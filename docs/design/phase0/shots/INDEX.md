- Offline: killing the fake desk did not produce a visible offline state on Charts (see above). The Desk page offline state (8859 stopped) was not captured: the page could not be re-served afterwards without restarting.
- "Server Chicago" chip and Server Updates card with data: the fake server has only "This Mac" and no deploy route ("Could not read it").
- Changes (7 days) with Put back, and old-to-new before Save: not on the Lab page DOM (searched innerText/HTML for "Put back" and "Changes (7"): none present in this state. Reaching them needs an edited and saved strategy, which would write to the repo's strategies folder, so skipped.
- Chart trading ON from the Desk Settings: returns the "Refused - Not Found" toast in lab mode (kept as an error-state shot). The ON state is shown on Charts through the plain fake desk.
- A real long list / very long name: only as the labelled JS MOCK.
- DOM, Tape, Heat map views of Charts were not opened (no book or tape in replay).
- Light/dark of every dialog at 1024 not taken for all Charts dialogs (Charts settings, order panel taken at 1440 light only).
